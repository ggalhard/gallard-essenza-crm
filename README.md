# Caderno Gallard

App instalável (PWA) de CRM offline pra Gallard Essenza — clientes,
pedidos, follow-up, estoque e financeiro.

**Repositório público, sem dado de negócio.** Só o código do app fica
aqui. Todo dado real (clientes, pedidos, valores) é digitado e salvo
**só no navegador de quem usa** (`localStorage`) — nunca é enviado pra
nenhum servidor, nem passa por esse repositório.

## Instalar no celular

1. Abrir [ggalhard.github.io/gallard-essenza-crm](https://ggalhard.github.io/gallard-essenza-crm/) no navegador do celular
2. **Android (Chrome):** menu ⋮ → "Instalar app" (ou o banner que aparece sozinho)
3. **iPhone (Safari):** botão de compartilhar → "Adicionar à Tela de Início"

Depois de instalado, abre como app de verdade — ícone próprio, sem barra
de navegador — e continua funcionando sem internet.
